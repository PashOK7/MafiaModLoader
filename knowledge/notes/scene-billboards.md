# Native billboards in world-ray scenes

Introduced 2026-11-02 at reflection step13. The dated inventory/design below precedes the completed
opt-in provider gate. Both-build source/material/camera-invariance/fault acceptance is recorded in
[MODDING.md](../../docs/MODDING.md), and world-source water integration followed at steps18/19.
The supported-mode/borrow/unknown rules remain current; broader water acceptance remains open in

Checked native disassembly/decompile in BOTH builds: ProductBillMatrix is LS3DF+6090 in1.2 and+6030
in1.0; m_AddFGroups is+73C0/+71C0. Billboard visual kind at+1D4 is BBRD (44524242). Rotation axis is
uint32 at+21C. Mode at+220 is uint32 in1.2 (0..3), a byte boolean in1.0. Do not share the1.2 mode layout
with1.0. The camera-dependent render matrix is at+224, distinct from the original world matrix at+10.
Flags+1D8 bit10000 denotes a proxy: m_AddFGroups takes its axis/mode from the source visual at+8, queues
that source, then substitutes the proxy visual and computes the proxy render matrix. The source must be
resolved before reading rotation parameters. Native world-space bit40 selects identity render coordinates.

Native inventory (build/reflection-block-20261101/billboard-inventory-v1.json) samples current broad city
coverage without temporarily enabling the whole city:1.2 has270 missing billboards,1.0 has141. Their modes
are full facing (axis2/mode0:217/119) and cylindrical Y (axis1/mode1:53/22). All sampled missing billboards
are non-proxies. Earlier whole-city baseline counts differ (506); these counts describe specific coverage,
not universal scene completeness. Native state restoration passes in both labs after inventory. The probe
mod is unloaded and remains disabled in both manifests.

For supported modes the native rotated matrix equals an orthonormal local rotation times the original
world matrix, with unchanged translation. Compute the observer in ORIGINAL local coordinates, derive that
rotation, then rotate the base-local ray into billboard-local coordinates. This preserves ray distance and
works with scaled original transforms. It must use the reflected path's observer, not the main camera's
pitch/FOV or a frozen matrix+224. Every original vertex/UV/material remains associated with its source.
The broad phase needs a conservative rotation bound, not the main-camera quad's thin bounds.

Modes outside the required inventory and degenerate observer/axis cases need explicit handling/UNKNOWN;
they cannot silently use an ordinary triangle. Native prelighting/emissive behavior, proxy lifetime,
animation and source fog restoration still need validation before this provider is complete.
